# AI Chatbot for Students

A Rule-Based AI Chatbot built with Python for assisting students with FAQs related to courses, assignments, exams, timetables, and support. Developed as part of the **CodSoft Artificial Intelligence Internship (Week 2 Project)**.

## Features
- **Text Preprocessing**: Lowercase conversion and punctuation cleaning.
- **Intent Detection**: Keyword matching mechanism to parse user queries.
- **Exception Handling**: Safe handling of missing files, empty inputs, and runtime errors.
- **Modular Codebase**: Clean separation of logic, dataset, and execution script.
